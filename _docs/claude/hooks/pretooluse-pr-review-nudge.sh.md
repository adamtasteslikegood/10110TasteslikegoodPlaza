## Overview

This Bash hook runs on PreToolUse for Bash-invoked GitHub CLI (gh) commands and implements a set of prioritized nudges and guards around pull request review and merge operations. It inspects the incoming tool payload to ensure it only runs for Bash gh invocations, parses the requested command text, and evaluates several triggers in order: a deny-and-redirect for `gh pr view --comments`, a merge guard that queries PR review threads via the GitHub GraphQL API and can deny, allow, or ask for human confirmation, and informational nudges that remind agents to read and reply to review comments using the full set of API surfaces. The script is fail-open for transient errors (exits 0 on error) except that when the merge guard cannot determine thread state it returns an explicit ask decision so a human must confirm before merging.

## Maintenance Notes

- Detect Bash invocations of the GitHub CLI and parse the invoked gh command from the PreToolUse payload.
- Deny usage of `gh pr view --comments` and instruct callers to use specific gh api endpoints that return all review surfaces.
- Act as a merge guard before `gh pr merge` by resolving the PR, querying its reviewThreads via GraphQL, and denying merges with unresolved review threads or asking if the guard cannot determine state.
- Emit informational nudges prior to `gh pr comment`, `gh pr review`, or GET calls for pull request comments reminding agents to verify reviews and sign replies appropriately.
- Operate fail-open on errors (trap to exit 0) so transient failures do not block other tooling, with the merge guard returning an explicit ask on ambiguous lookups.
