## Overview

This directory contains shell hook(s) that run during PreToolUse for Bash-invoked GitHub CLI (gh) commands. At the root there is a single Bash script, pretooluse-pr-review-nudge.sh, which implements a prioritized set of nudges and guards around pull request review and merge operations. The script is intended to intercept or augment gh commands invoked from Bash to help enforce review/merge policies and to surface review-related guidance before destructive actions occur.

Because there are no subdirectories, the directory is intentionally flat: each file at the root represents a hook that can be installed or sourced into a developer's environment. Together, the components in this directory serve as a protective layer executed before GitHub CLI actions, improving reviewer/merger behavior and reducing accidental merges without proper review. This directory's role in the larger system is to provide pre-execution checks and user-facing nudges specific to pull request review flows tied to the gh CLI when invoked from Bash.


### File Organization

All hook scripts live at the directory root in a flat layout. Each file is a standalone Bash hook that can be installed or sourced independently. The organization keeps hook implementations isolated, making it straightforward to add, remove, or update individual hooks without navigating nested folders.
