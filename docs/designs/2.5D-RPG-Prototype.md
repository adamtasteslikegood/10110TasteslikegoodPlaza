## Vision

### 10x Check
Instead of building a full 3D first-person environment (which requires complex art, navigation meshes, and physics tuning), we pivot to a highly stylized 2.5D top-down RPG perspective (think Pokemon or Stardew Valley). This drastically reduces asset creation time and focuses entirely on the core interaction loop: walking up to an agent, seeing their portrait, and interacting via a chat interface. It acts as a visual "South Park cutout" skin over the real 137 CLI agents.

## Accepted Scope (added to this plan)
- 2.5D Top-Down perspective (Godot 2D).
- 1 generic agent sprite asset, tinted dynamically by department color.
- 1 generic silhouette portrait for dialogue UI.
- Python WebSocket bridge enforcing synchronous execution with timeout protection.
- Godot dialogue UI implements "typewriter" effect to simulate streaming from full JSON response.
- Background task delegation UI for long-running processes (future phase).
